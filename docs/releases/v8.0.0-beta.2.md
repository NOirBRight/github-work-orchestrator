# GWO V8 Beta2 — Feature Complete Preview

## Release boundary

This is the GWO V8 **feature-complete preview**. Repository acceptance is
**Local Verification Only**; GitHub Actions and hosted acceptance are disabled.

Beta2 does **not**:

- admit production work;
- activate the V8 default writer or change writer authority;
- create an Activation Receipt;
- execute Issue #118 or the GA root Canary in Issue #119.

The preview is exercised only through an isolated temporary target with
`preview_mode="beta2_isolated_preview"` and
`writer_activation_enabled=False`.

## Included scope

- #113 wake and watchdog convergence;
- #114 CandidateGate authoritative Candidate readback;
- #115 bounded Formal Review and Repair Verification;
- #116 exact Batch delivery boundaries;
- #117 deterministic Batch recovery and Singleton fallback;
- #137 Candidate/Review/Repair scope-invalidation routing;
- isolated V8 production composition behind `start`, `advance`, and `inspect`.

## Verification

The release is accepted with local Python 3.13 verification, the package
manifest readback, the repository quick validator, focused V8 suites, the
full pytest suite, and clean-tree/diff checks. No CI URL, hosted check, or
workflow run is part of the release evidence.

The final merged commit, tree, ordered parents, local command logs, tracker
readbacks, and Beta2 publication identity are recorded in the external C2
release evidence. Issues #118 (Beta3) and #119 (GA) remain open and are not
part of this preview.
